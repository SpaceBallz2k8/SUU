❓ Mission Briefing (FAQ)

🔹 Is this free?
Yes, completely free. However it is not open source — proprietary but no cost.
🔹 What if I'm missing 7z.exe or nyuu.exe?
First run detection will alert you & offer to download all required tools from their official GitHub repos.
🔹 Can tools be updated?
Yes! Options → Check for Tool Updates. The app tracks version numbers from GitHub releases.
🔹 Does it create NZBs automatically?
Yes, after each job or batch, NZBs are generated.
🔹 Can uploads be scheduled?
Built-in scheduler with date/time activation.
🔹 Does it support PAR2 generation?
Yes, ParPar + legacy PAR2, configurable %.
🔹 Is this Windows only?
Yes, Windows x64 only. No Linux/macOS support planned.
